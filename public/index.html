API Documentation

Use this API to send messages programmatically from your linked WhatsApp account.

1. Send Message (GET)

Perfect for quick links or browser-based triggers.

GET /send?number=PHONE&message=TEXT

2. Postman / External Tools

To use with Postman or curl, include your API Key in the query string or as a header.

GET /send?number=PHONE&message=TEXT&apikey=wa_secret_123

Header Auth: You can also send the key in the header x-api-key: wa_secret_123
